# Литературное мастерство и интертекст

ИИ-наставник и учебник, который ведёт **с нуля** по школьному литературному канону восьми стран — **России, США, Великобритании, Франции, Германии, Японии, Южной Кореи и Турции**, — по мировым мифологиям и по главным книгам мировой литературы вне школьных программ. Цель — не просто «прочитать классику», а научиться **точно ссылаться** на неё, встраивать отсылки к мифам, легендам и крылатым выражениям в собственные рассказы — и использовать это в карьере **писателя и актрисы**.

Требовательность — по модели НИУ ВШЭ: 10-балльная шкала, накопленная оценка, блокирующие элементы, дедлайны и экзамены. Спрашивает Наставник строго, но всё непонятное объясняет подробно — пока не станет ясно.

## Мастерская — `dramaturgy/` (ядро курса)

Произведения здесь не пересказываются — они **разбираются как механизмы**: драматический вопрос, желание и потребность героя, конфликт, где стоят поворотные точки и почему, как дозирована информация (тайна / напряжение / драматическая ирония), почему выбран этот рассказчик, как устроена ключевая сцена, финал. Каждый разбор кончается тремя блоками: **«что украсть»** (приём как инструкция себе), **«ошибка подражателя»** и **«мой текст»** — этюд, который пишете вы.

- `dramaturgy/00-instrumenty.md` — инструментарий и **карта разбора** (начните здесь);
- `dramaturgy/01–12` — эталонные разборы ~90 произведений: античность, Библия, Россия, Британия, США, Франция, Германия, Япония, Корея, Турция, мировая классика;
- `dramaturgy/README.md` — таблица **«приёмы по задачам»** (как начать, как ввести героя, диалог с подтекстом, сцена узнавания, финал…).

Через год у вас — портфолио из 80+ этюдов в технике мастеров (`student/portfolio.md`), из которых собираются рассказы.

## Лекционный курс — `lectures/` (контекст)

Справочник: кто, когда, о чём, какой миф в основе. Нужен, чтобы понимать происхождение текста, но не заменяет разбора.


**23 лекции** для конспектирования (≈ 530 тысяч знаков, около 300 страниц). Каждая: зачем это знать → ключевые термины → конспект с таблицами → расширение кругозора → «для актёра» → вопросы для самопроверки → практикум (базовый / продвинутый / творческий / для актёра).

| Часть | Лекции |
|---|---|
| I. Основы теории литературы | 1. Роды, жанры, направления · 2. Анатомия текста · 3. Теория интертекста |
| II. Миф | 4. Теория мифа, Пропп, Кэмпбелл · 5. Греческая мифология · 6. Гомер и трагедия · 7. Библия · 8. Месопотамия, Египет, Индия, Иран, Китай · 9. Славяне, германцы, кельты, Япония, Корея, тюрки |
| III. Национальные литературы | 10–12. Россия · 13. Британия · 14. США · 15. Франция · 16. Германия · 17. Япония · 18. Корея · 19. Турция · 20. Мировая классика вне программ (Данте, Сервантес, «1001 ночь», Китай, Борхес, Маркес, Ибсен, Андерсен…) |
| IV. Мастерство | 21. Проза и технология отсылки · 22. Литература для актёра: Станиславский, Чехов, Брехт, сценическая речь, репертуар · 23. Карьера: писатель и актриса |

Как конспектировать — `lectures/README.md` (метод Корнелла).

## Как запустить

### Вариант 1. Claude Code (рекомендуется: прогресс сохраняется в файлах)

```bash
git clone <этот репозиторий>
cd student-literate-course
claude
```

В этой папке Claude автоматически становится Наставником — мастером писательского семинара (правила — в `CLAUDE.md`). Начните с команды:

```
/start
```

### Вариант 2. Проект на claude.ai — одним файлом

1. Скачайте файл **`kurs-literaturnoe-masterstvo.md`** (весь курс в одном файле, ~1,4 МБ).
2. На claude.ai: **Projects → Create project**, назовите, например, «Литературное мастерство».
3. В **Project instructions** вставьте текст из `tools/project-instructions.md`.
4. В **Project knowledge** загрузите `kurs-literaturnoe-masterstvo.md`.
5. Откройте новый чат в проекте и напишите: **«Диагностика»**.
6. В конце каждого занятия напишите **«Итог занятия»** — Наставник выдаст блок «ВЕДОМОСТЬ — ОБНОВЛЁННАЯ». Сохраните его в файл `moya-vedomost.md` и загрузите (замените) в знаниях проекта — так прогресс переживёт переход в новый чат.

Если материалы в репозитории изменятся, пересоберите файл: `python3 tools/build_bundle.py`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Входная диагностика, заполнение профиля, корректировка программы |
| `/razbor <произведение> [этюд]` | **Главная команда.** Разбор по карте драматургии: ваша карта → сравнение с эталоном → украденный приём → разбор вашего этюда как на семинаре → переписывание |
| `/lecture [N]` | Пройти лекцию-контекст: вопросы, развёрнутые объяснения, практикум |
| `/explain <что непонятно>` | Подробное объяснение любой темы «с нуля» — пока не станет понятно |
| `/actor <задача>` | Актёрский трек: анализ роли, логика речи, программа чтеца, холодная читка |
| `/lesson [тема]` | Занятие по текущей неделе: разминка, проверка ДЗ, контроль чтения, новый материал, творческое задание |
| `/seminar <тема>` | Семинар: проблемный вопрос, ваша позиция, контраргументы, оценка |
| `/quiz [N] [традиция]` | Опрос по вашей картотеке аллюзий (интервальное повторение) |
| `/exam <модуль>` | Модульный экзамен: билет из 4 вопросов, расчёт итоговой оценки |
| `/allusion <замысел>` | Подбор отсылок из разных традиций под сцену или героя вашего рассказа |
| `/workshop <файл>` | Разбор вашего рассказа: карта отсылок, проверка точности, оценка |
| `/progress` | Ведомость: оценки, долги, прогноз |

Субагенты: `literature-mentor` (сам Наставник) и `quote-checker` (проверка цитат и атрибуций по источникам).

## Программа в двух словах

1. **Модуль 1. Основы и миф** (нед. 1–10) — теория литературы и интертекста, теория мифа, Греция, Гомер, трагедия, Библия, древний мир.
2. **Модуль 2. Европейский канон** (нед. 11–21) — славяне, германцы, кельты; Россия, Британия, Франция, Германия; Данте, Сервантес.
3. **Модуль 3. США, Восток и мир** (нед. 22–32) — США, Япония, Корея, Турция; «1001 ночь», Китай, Латинская Америка, Северная и Восточная Европа, Африка.
4. **Модуль 4. Мастерская** (нед. 33–42) — проза и технология отсылки, актёрское мастерство и сценическая речь, карьера; курсовой проект (цикл рассказов или монодрама) и защита.

Нагрузка — 8–10 часов в неделю; если времени меньше, Наставник растянет программу.

## Оговорка о точности

Списки школьных программ составлены по устойчивому ядру, а не по документу конкретного года: в США и Германии программы различаются по штатам и землям, во Франции список для bac обновляется ежегодно. Цитаты и атрибуции проверяйте агентом `quote-checker`; места в лекциях с пометкой «сверяйте по изданию» требуют проверки особенно — Наставник запрограммирован признавать неуверенность, а не выдумывать.
