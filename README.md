# Курс: литературное мастерство и интертекст — от читателя к автору

Учебный курс с агентом-ментором (Claude Code или Codex). С нуля: школьный литературный канон восьми стран — России, США, Великобритании, Франции, Германии, Японии, Южной Кореи и Турции, — мировые мифологии и главные книги вне программ, а также теоретический минимум магистратуры по литературному мастерству: поэтика рассказа, повести и романа, методы филологии, русский поэтический канон, современная русская литература, западный роман-модерн, театр XX–XXI веков, автофикшн, основы сторителлинга и редактирования. Через **разбор с точки зрения драматургии** (как сделано и что украсть) — к собственному **сборнику рассказов** с осознанной техникой отсылки. Параллельно — литературная подготовка актрисы и карьерный трек. Сверх ядра — **семь треков по выбору**: сценарий, перевод с английского, эссе и критика, медиа и копирайтинг, редактура, литменеджмент, роман и пьеса.

Новой ученице — [ONBOARDING.md](ONBOARDING.md): установка, первая сессия, работа в VS Code, учёба на нескольких устройствах, приватность.

## Расчётные параметры

| Параметр | Значение |
|---|---|
| Ядро | 53 недели при номинале **9 ч/нед** (+ неделя аудита) — исходный маршрут, не срок каждой |
| Бюджет времени | номинал 9 ч/нед; личные сроки по расписанию — `bin/plan.py`, [планирование](mentoring/planning.md) |
| Суммарно | Ядро 471 час: 6 часов аудита + 465 часов этапов 1–6; каждый трек — ещё 40–72 часа |
| Темы и проверки | Ядро: 44 темы × 3 пакета (теория, карта разбора, этюд), 6 чекпоинтов; треки: 33 темы, 7 чекпоинтов |
| Подачи и прослушивания | первые шаги с этапа 3, основная работа — этап 6 |

Свои даты ученица получает после онбординга: агент спрашивает расписание и считает сроки (`bin/plan.py`), даты записываются только после согласования. Календарь пересчитывается по фактическим часам.

Целевое ядро:

`Инструменты автора → миф → русская литература → Европа и Америка → Восток и мировая классика → Сборник и выход в профессию`

Треки встраиваются после своего этапа (например, сценарий — после этапа 4).

## Процесс обучения с проверкой

Откройте этот каталог в Claude Code или Codex. В Codex правила подхватываются из `AGENTS.md`; в Claude Code — из `CLAUDE.md` и локальных skills.

| Команда | Что делает |
|---|---|
| `/status` | Где я, что просрочено, отстаю ли от плана, что дальше |
| `/learn [тема]` | Тема порциями: теория и вопросы → карта разбора → этюд этапами |
| `/check [тема]` | 5 заданий без подсказок: разбор незнакомого фрагмента, механизм, перенос, точность, авторский выбор |
| `/check cpN` / `cptN` | Сдача чекпоинта этапа или трека: 10 вопросов гейта + проверка артефакта вживую |
| `/review` | Повторения закрытых тем по слабым местам: 7 / 21 / 60 / 150 дней |
| `/mock [формат]` | Мок-разговор: редактор, семинар, коллоквиум в театральный вуз, кастинг |

В Codex те же действия можно просить обычным текстом: «покажи статус», «продолжим тему», «проверь меня», «проведи повторение».

Темы и чекпоинты — в `course/topics.json`; состояние — в `state/topics.json`; протоколы проверок — в `state/checks/`; арифметика повторений — в `bin/track.py`. Подробно: [10-learning-loop.md](10-learning-loop.md).

Порядок при смене модели: [контракт ментора](mentoring/harness.md), указатель текущего шага `state/lesson.json`. `python3 bin/lesson.py context` даёт короткий контекст без сети. Для продолжения после переключения достаточно «Продолжим по harness».

Учимся с самых основ, цельными блоками связанных понятий, с пакетами вопросов и постепенно убывающей помощью. **Главное правило: разбор, а не пересказ** — о любом тексте говорим языком драматургии, и каждый урок кончается вашим текстом. Договорённости: [формат обучения](mentoring/format.md).

## Что сознательно НЕ входит в ядро

Роман, пьеса, сценарии, перевод, критика, копирайтинг, профессиональная редактура и литменеджмент — **только в треках по выбору**, не в этапах 1–6: в ядре цель одна — сборник рассказов с осознанной техникой. Поэзия как основной жанр не входит никуда: русский поэтический канон изучается как источник отсылок, а не как жанр для письма.

Короткие стихотворные формы (хайку, сиджо, газель, сонет) и сцена-пьеса появляются точечно как упражнения внутри этапов, без углубления.
