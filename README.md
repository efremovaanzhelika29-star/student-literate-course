# Литературное мастерство и интертекст

ИИ-наставник, который ведёт вас по школьному литературному канону восьми стран — **России, США, Великобритании, Франции, Германии, Японии, Южной Кореи и Турции** — и по мировым мифологиям. Цель — не просто «прочитать классику», а научиться **точно ссылаться** на неё и встраивать отсылки к мифам, легендам и крылатым выражениям в собственные рассказы.

Требовательность — по модели НИУ ВШЭ: 10-балльная шкала, накопленная оценка, блокирующие элементы, дедлайны и экзамены.

## Как запустить

### Вариант 1. Claude Code (рекомендуется: прогресс сохраняется в файлах)

```bash
git clone <этот репозиторий>
cd student-literate-course
claude
```

В этой папке Claude автоматически становится Наставником (правила — в `CLAUDE.md`). Начните с команды:

```
/start
```

### Вариант 2. Обычный чат (claude.ai Projects и т. п.)

Скопируйте текст из `SYSTEM_PROMPT.md` в инструкции проекта, а файлы из `curriculum/` загрузите в базу знаний проекта. Ведомость придётся обновлять вручную (Наставник в конце занятия выдаёт блоки для копирования).

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Входная диагностика, заполнение профиля, корректировка программы |
| `/lesson [тема]` | Занятие по текущей неделе: разминка, проверка ДЗ, контроль чтения, новый материал, творческое задание |
| `/seminar <тема>` | Семинар: проблемный вопрос, ваша позиция, контраргументы, оценка |
| `/quiz [N] [традиция]` | Опрос по вашей картотеке аллюзий (интервальное повторение) |
| `/exam <модуль>` | Модульный экзамен: билет из 4 вопросов, расчёт итоговой оценки |
| `/allusion <замысел>` | Подбор отсылок из разных традиций под сцену или героя вашего рассказа |
| `/workshop <файл>` | Разбор вашего рассказа: карта отсылок, проверка точности, оценка |
| `/progress` | Ведомость: оценки, долги, прогноз |

Субагенты: `literature-mentor` (сам Наставник) и `quote-checker` (проверка цитат и атрибуций по источникам).

```
student/

  allusion-bank.md         картотека аллюзий для повторения

```

## Программа в двух словах

1. **Модуль 1. Фундамент: миф и Писание** — Гесиод, Гомер, Овидий, греческая трагедия, Библия.
2. **Модуль 2. Европейский канон** — Россия, Великобритания, Франция, Германия + славянская, кельтская и германо-скандинавская мифология.
3. **Модуль 3. США и Восток** — США, Япония, Южная Корея, Турция + японская, корейская и тюркская мифология.
4. **Модуль 4. Мастерская интертекста** — Пропп и Кэмпбелл, техники отсылки, разбор мастеров (Джойс, Булгаков, Гейман, Миллер, Мураками), курсовой проект: цикл рассказов с авторским комментарием и защита.

Нагрузка — 6–8 часов в неделю; если времени меньше, Наставник растянет программу.

## Оговорка о точности

Списки школьных программ составлены по устойчивому ядру, а не по документу конкретного года: в США и Германии программы различаются по штатам и землям, во Франции список для bac обновляется ежегодно. Цитаты и атрибуции проверяйте командой `quote-checker` — Наставник запрограммирован признавать неуверенность, а не выдумывать.
