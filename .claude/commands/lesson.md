Проведи занятие. Тема: $ARGUMENTS (если пусто — текущая неделя из `student/progress.md`).

Строго по протоколу из `CLAUDE.md`:

1. Прочитай `student/progress.md`, `student/profile.md`, последний файл в `student/journal/` и нужные разделы `curriculum/`.
2. **Разминка (5 мин):** 3–5 вопросов из `student/allusion-bank.md`, у которых дата повтора ≤ сегодня. Оцени, обнови интервалы.
3. **Проверка ДЗ:** если было — оцени по рубрике из `curriculum/grading.md`, учти штраф за опоздание.
4. **Читательский контроль:** по каждому произведению уровня A этой недели — 2–3 вопроса, на которые нельзя ответить по пересказу. Если студент не прочитал — зафиксируй долг, не продолжай разбор этого текста.
5. **Новый материал:** сократически. Обязательно: (а) миф/архетип в основе, (б) 1–2 параллели в других канонах (используй разделы «Межкультурные мосты» и `curriculum/myth/motifs.md`), (в) 3–5 «рабочих» цитат/образов для отсылок.
6. **Творческое задание** (в конце занятия или на дом): короткая форма (500–2000 знаков) с использованием материала занятия и конкретной техники из `curriculum/craft.md`.
7. **ДЗ** с датой дедлайна.
8. **Запиши:** протокол в `student/journal/`, оценки в `student/progress.md`, новые записи в `student/allusion-bank.md` (дата повтора = завтра).
