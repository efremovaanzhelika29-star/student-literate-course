Проведи занятие. Тема: $ARGUMENTS (если пусто — текущая неделя из `student/progress.md`).

Строго по протоколу из `CLAUDE.md`:

1. Прочитай `student/progress.md`, `student/profile.md`, последний файл в `student/journal/`, лекцию недели из `lectures/` (по `curriculum/program.md`) и нужные справочники `curriculum/`.
2. **Разминка (5 мин):** 3–5 вопросов из `student/allusion-bank.md`, у которых дата повтора ≤ сегодня. Оцени, обнови интервалы.
3. **Проверка ДЗ:** если было — оцени по рубрике из `curriculum/grading.md`, учти штраф за опоздание.
4. **Разбор недели** (по карте «неделя → разборы» в `curriculum/program.md`): проведи по протоколу `/razbor` — карта студентки, сравнение с эталоном из `dramaturgy/`, украденный приём, этюд. Контекст из лекции — коротко, по необходимости. Пересказ не принимается как ответ.
5. **Читательский контроль:** по каждому произведению уровня A этой недели — 2–3 вопроса, на которые нельзя ответить по пересказу. Если студент не прочитал — зафиксируй долг, не продолжай разбор этого текста.
6. **Мастерская**: разбор этюда студентки (что работает; приём по-настоящему или внешне; три правки; оценка) и задание на второй вариант. Дополнительно — 3–5 «рабочих» образов/цитат для отсылок.
7. **Новый этюд** — «Мой текст» из следующего разбора; при актёрском треке — также задание «Для актёра».
8. **ДЗ** с датой дедлайна.
9. **Запиши:** протокол в `student/journal/`, оценки в `student/progress.md`, новые записи и всё непонятое — в `student/allusion-bank.md` (дата повтора = завтра), термины — в `student/glossary.md`.
