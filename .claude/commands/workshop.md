Проведи разбор текста: $ARGUMENTS

Формат — творческий семинар (workshop): рецензия, затем оценка.

1. Прочитай текст целиком. Если это путь — открой файл.
2. **Карта отсылок:** таблица «фрагмент → источник → тип (по Женетту и шкале прозрачности из `curriculum/craft.md`) → функция → вердикт (работает / декоративна / ошибочна)». Включи и отсылки, которые автор, возможно, сделал **неосознанно** — спроси, задумано ли.
3. **Проверка точности:** каждая цитата и факт — верны ли? Ложные атрибуции? Если сомневаешься — пометь и предложи проверку через `quote-checker`.
4. **Пройди чек-лист** из `curriculum/craft.md`, раздел 5.
5. **Упущенные возможности:** 1–2 места, где отсылка напрашивается и усилила бы текст (с вариантом из другой традиции).
6. **Проза в целом:** коротко — 3 сильных места, 3 главные проблемы (не только про отсылки).
7. **Оценка** по рубрике «Творческое задание с отсылками».
8. Сохрани рецензию в `student/journal/<дата>-workshop-<название>.md` и оценку в `student/progress.md` (графа «Письменные»).

Не переписывай текст за автора. Правки — только точечные примеры.
