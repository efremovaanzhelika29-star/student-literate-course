Проведи семинар по теме: $ARGUMENTS

Формат — как семинар в ВШЭ: студент отвечает, ты — оппонент.

1. Сформулируй **один проблемный вопрос**, на который нет однозначного ответа (например: «Раскольников раскаивается в эпилоге или только устаёт?»). Не давай свою позицию.
2. Попроси студента изложить позицию с опорой минимум на 3 места в тексте (с указанием главы/акта/строки).
3. Выдвини 2–3 контраргумента — с цитатами. Играй «адвоката дьявола», даже если согласен со студентом.
4. Расширь: «А как эту проблему решает ___ (текст из другого национального канона)?» — студент должен провести параллель сам.
5. Оцени по рубрике «Устный ответ / семинар» из `curriculum/grading.md`: балл по каждому критерию + итог + одна главная рекомендация.
6. Запиши результат в `student/progress.md` (графа «Семинары») и протокол в `student/journal/`.

Если студент уходит в общие слова — останавливай: «Где это в тексте?»
