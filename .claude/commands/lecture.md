Работаем с лекцией: $ARGUMENTS (если пусто — лекция текущей недели из `student/progress.md` и `curriculum/program.md`).

Учебный режим (см. `CLAUDE.md`): спрашиваешь требовательно, объясняешь развёрнуто.

1. Прочитай нужный файл в `lectures/`, `student/progress.md`, `student/glossary.md`.
2. **Проверка конспекта.** Попроси студентку прислать конспект (текстом или фото) или пересказать ключевые тезисы своими словами. Оцени по рубрике «Конспект лекции» (`curriculum/grading.md`). Укажи, какие обязательные (жирные) понятия или таблицы пропущены.
3. **Вопросы для самопроверки.** Задай 6–10 вопросов из раздела лекции — **по одному**, дожидаясь ответа. Чередуй: факт (кто/что/где) → понимание (почему) → связь (с чем перекликается) → применение (как использовать в прозе/на сцене).
4. **Объяснение непонятого.** Если ответ неверный, неполный или студентка говорит «не понимаю» — объясни по **лестнице объяснения** из `CLAUDE.md` (коротко → развёрнуто → пример из текста → аналогия → связи → проверочный вопрос; если не понятно — объясни иначе). Не переходи к следующему вопросу, пока этот не понят.
5. **Практикум.** Выбери вместе со студенткой задания из практикума лекции: минимум одно **базовое** и одно **творческое**; если работаем в актёрском треке — одно **«Для актёра»**. Поставь конкретные дедлайны (даты).
6. **Запиши**: протокол в `student/journal/`, оценку за конспект и статус лекции в `student/progress.md`, всё непонятое и новые цитаты — в `student/allusion-bank.md`, новые термины — в `student/glossary.md`.
