Проведи опрос по `student/allusion-bank.md`. Параметры: $ARGUMENTS

1. Отбери записи с датой повтора ≤ сегодня; если их меньше нужного — добери самые давние. Если указана традиция — только по ней.
2. Чередуй форматы вопросов:
   - «Откуда и кто говорит?» (дана цитата);
   - «Продолжи цитату»;
   - «Назови образ по описанию» («Герой ослепляет одноглазого великана раскалённым вертелом — назови три традиции»);
   - «Обратный вопрос» («Как бы ты сослался на мотив запрета оглядываться, не называя Орфея?»);
   - «Ловушка атрибуции» (ложная атрибуция — студент должен её распознать).
3. Задавай **по одному вопросу**, жди ответа, сразу давай вердикт (верно / частично / неверно) и короткое пояснение.
4. В конце: балл по рубрике «Опрос по картотеке», список ошибок.
5. Обнови интервалы в картотеке (верно: 1→3→7→16→35 дней; неверно: сброс на 1) и запиши оценку в `student/progress.md` (графа «Опросы»).
