---
description: Входная диагностика и заполнение профиля студента (первое занятие)
---

Проведи входную диагностику студента — как вступительное собеседование на магистерскую программу.

1. Прочитай `CLAUDE.md`, `curriculum/program.md`, `curriculum/grading.md` и `student/profile.md`.
2. Задавай вопросы **по одному блоку за раз**, дожидаясь ответа:
   - **Блок 1. Читательская биография.** Какие произведения из `curriculum/canon/*.md` студент уже читал полностью (попроси перечислить по странам, без подсказки списком), на каких языках читает.
   - **Блок 2. Проверка знания.** 10 вопросов возрастающей сложности: 3 по греко-римской мифологии, 2 по Библии, 3 по русской классике, 2 по любому иностранному канону. Требуй источник и контекст. Каждый ответ оцени 0/0,5/1.
   - **Блок 3. Письмо.** Попроси прислать фрагмент своей прозы (до 5000 знаков) или написать за 20 минут абзац, где есть хотя бы одна отсылка. Оцени по рубрике «Творческое задание».
   - **Блок 4. Цели и ресурс.** Сколько часов в неделю реально есть; какие жанры пишет; какие традиции интересуют больше всего.
3. По итогам:
   - заполни `student/profile.md` (уровень по каждой традиции: 0 — не знаком, 1 — фрагментарно, 2 — уверенно, 3 — глубоко);
   - в `student/progress.md` выставь дату старта, текущую неделю 1 и диагностическую оценку (она не входит в формулу, это точка отсчёта);
   - если нагрузка < 6 ч/нед, предложи растянуть программу (каждая неделя → 1,5–2 недели) и зафиксируй это в профиле;
   - предложи 2–3 корректировки программы под профиль (например, если греческая мифология уже на уровне 3 — сократить недели 2–3 до одной).
4. Выдай первое домашнее задание недели 1 с конкретным дедлайном (дата).
5. Создай протокол `student/journal/<сегодняшняя дата>-диагностика.md`.

Тон — вежливый, деловой, без заискивания. Студент должен почувствовать планку.
