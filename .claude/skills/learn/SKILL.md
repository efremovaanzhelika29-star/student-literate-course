# /learn [тема]

Перед началом: `mentoring/harness.md` (если не прочитан в этой сессии), `mentoring/lesson-packets.md`, `python3 bin/lesson.py context`. Продолжать с сохранённого шага, не начинать заново.

## Выбор темы
- Без аргумента — по приоритету из `./bin/track.py status`: повторения (до 15 мин) → `shaky` → активная → новая.
- Новая тема: `./bin/track.py start <тема>`; источники — в `course/topics.json` (`sources`), этап — в `0N-stage-*.md`.

## P1 — теория и вопросы
1. Объявить пакет (номер, объём, время, файл ответа). `python3 bin/practice.py init <тема>-P1 --questions N`; `python3 bin/lesson.py set --ref <тема>-P1 --mode learn --step "…"`.
2. Одним сообщением: связный блок (3–4 понятия, механизм, пример из текста с местом, типичная ошибка, связь с письмом) + 5–8 нумерованных вопросов + (если уместно) прогноз до чтения продолжения.
3. **Разбор, а не пересказ**: вопросы — о том, как сделано и зачем. Перед разбором произведения — две-три фразы о нём (ученица учится с нуля).
4. Ответ — одним сообщением или в `answer.md`. На «проверь <пакет>»: прочитать файл, `python3 bin/practice.py run <пакет>`, сводка, ошибки по одной (`lesson.py set … --await-fix`). Ученица исправляет сама.
5. Все пункты верны → протокол `state/checks/ГГГГ-ММ-ДД-<пакет>.md` (`type: packet`, честный `help:`) → `./bin/track.py packet-pass <пакет> --protocol …`.

## P2 — карта разбора
`practice.py init <тема>-P2` → ученица заполняет `map.md` до эталона → проверка (механика, точность, глубина, приём-инструкция) → эталон из `knowledge/dramaturgy/` → сравнение → ошибки по одной → протокол → `packet-pass`.

## P3 — этюд этапами
`practice.py init <тема>-P3` (план) → проверка плана → `--practice --stage 1` (черновик) → `practice.py run` → разбор как на семинаре: что работает (с цитатой), приём по-настоящему или внешне, **три** правки, вердикт словами → `--stage 2` (второй вариант, «Что изменено и почему») → разбор → протокол → `packet-pass`. Следующий этап — только после разбора текущего. Файлы в `practice/` не править; пример правки — только в чате.

## Помощь убывает
Разобранный пример → пропуски → самостоятельный этюд → перенос. При «не понимаю» — лестница объяснения из `mentoring/harness.md`. Полное решение — только по прямой просьбе (тогда пункт не самостоятельный, `help: shown`).

## Граница блока, пауза, конец
Обновить `state/lesson.json` (`lesson.py set`), записать сессию в `state/sessions/`, `python3 bin/lesson.py validate`. Новые цитаты — `state/allusion-bank.md`, термины — `state/glossary.md`, приёмы и этюды — `state/portfolio.md`. Когда все три пакета пройдены — предложить `/check <тема>`.
