# /check [тема | cpN | cptN]

## Перед проверкой
- Тема: все пакеты пройдены (`./bin/track.py status --mentor`); иначе назвать, что осталось, и вернуться к `/learn`.
- Чекпоинт: `./bin/track.py cp CPn` (или `CPTn` для трека) — все темы этапа/трека закрыты; артефакт существует (`0N-stage-*.md`, `1N-track-*.md`, `07-project-a.md`).
- Прочитать прошлые протоколы этой темы/чекпоинта в `state/checks/`: **не повторять** вопросы дословно; целиться в прошлые слабые места.
- `python3 bin/lesson.py set --ref <тема|CPn> --mode check --step "Задание 1"`.

## Проверка темы — 5 заданий, по одному, без подсказок
1. **Карта незнакомого фрагмента** — короткий текст, не разобранный на уроке, по 3–4 пунктам карты.
2. **Механизм** — «почему это работает» на материале темы.
3. **Перенос** — этюд до 1500 знаков с приёмом темы на новом материале.
4. **Контекст и точность** — источник, место, кто говорит; миф/традиция; ловушка атрибуции.
5. **Авторский выбор** — что автор выиграл и чем заплатил.

Документы — только как справка по факту (`help: docs`). Любая подсказка по механизму → `help: hints`: проверка не засчитывается как независимая.

## Чекпоинт
10 вопросов гейта (вариации вопросов `09-checkpoints.md` на новом материале) + **проверка артефакта вживую**: открыть файлы Сборника и практики, читать, спрашивать по тексту. Нет артефакта — чекпоинт не сдан.

## Протокол и трекер
- Протокол `state/checks/ГГГГ-ММ-ДД-<id>-check.md` по формату `10-learning-loop.md`: вердикты, баллы (по `mentoring/rubrics.md`), `weak:`, `evidence:`, разбор.
- Тема: `./bin/track.py close <тема> --protocol … [--weak "…"]`. Чекпоинт: `./bin/track.py cp CPn|CPTn --protocol … --artifact <путь>`.
- Статусы — только трекером; `state/topics.json` руками не править.

## Вердикт ученице — словами
Без баллов, порогов и интервалов:
- «Тема закрыта. Сильное: … Слабое место, к которому вернёмся на повторении: …»
- «Пока не закрыта. Что не получилось: … Что делаем: … Вернёмся к проверке после …»
- Чекпоинт: «Этап закрыт / не закрыт; по артефакту: …; по вопросам: …».

После вердикта — разбор ошибок по лестнице объяснения. Не подыгрывать.
