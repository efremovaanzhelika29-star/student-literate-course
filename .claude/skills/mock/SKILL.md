# /mock [редактор | семинар | коллоквиум | кастинг]

Только по закрытым темам и готовым частям Сборника. Формат по умолчанию — «редактор».

- **Редактор**: ментор читает рассказ из Сборника как редактор журнала: «почему этот финал?», «зачем эта отсылка?», «что объединяет рассказы?», «кто ваш читатель?». 20–30 минут.
- **Семинар**: обсуждение рассказа как на семинаре молодых авторов: что работает → где читатель выпал → три главных вопроса автору. Ученица молчит до конца обсуждения, затем отвечает.
- **Коллоквиум**: собеседование в театральный вуз по литературе и театру: «что вы читали последним и почему», любимый спектакль, вопросы по пьесам курса, о Станиславском, Чехове, Брехте; разбор одной роли из программы.
- **Кастинг**: незнакомая сцена из пьес курса, 10 минут на анализ (кто, где, хочу, мешает, событие), затем разбор анализа.

Правила: по одному вопросу; без подсказок; реалистичный тон. После — **честный разбор** по `mentoring/rubrics.md`: сильное, слабое, что подтянуть (со ссылкой на темы и пакеты). Протокол `state/checks/ГГГГ-ММ-ДД-mock.md` (`topic: MOCK`, `type: mock`). Мок статусы тем не меняет; если ответы показали провал закрытой темы — `./bin/track.py shaky <тема> --weak "…"`.
