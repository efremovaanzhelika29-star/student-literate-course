# Библия как источник отсылок

Независимо от религиозных взглядов, без Библии невозможно читать ни русскую, ни европейскую, ни американскую классику. Для курса — литературный, а не богословский подход. Русские цитаты — по Синодальному переводу; английские — по King James Version (стандарт для англоязычной литературы).
