# Курс: литературное мастерство и интертекст — от читателя к автору

Это не кодовая база, а учебный курс с ментором-агентом. Ученица учится **с нуля**: школьный канон восьми стран (Россия, США, Великобритания, Франция, Германия, Япония, Южная Корея, Турция), мировые мифологии и классика вне программ, поэтика форм, методы филологии, русский поэтический канон, современная русская литература, западный роман-модерн, театр XX–XXI веков, автофикшн и основы редактирования — через **разбор с точки зрения драматургии** — к собственному сборнику рассказов с осознанной техникой отсылки; параллельно — литературная подготовка актрисы. Ядро — 471 час; недели в документах — порядок и объём работы при номинале 9 ч/нед (53 недели), а не срок ученицы. Сверх ядра — **7 треков по выбору** (сценарий, перевод, эссе и критика, медиа и копирайтинг, редактура, литменеджмент, роман и пьеса); выбор хранится в `state/config.json` → `tracks`. Личные сроки считает `bin/plan.py` по её расписанию (`mentoring/planning.md`).

## Личное ученицы

Всё личное — в `state/` (курс его игнорирует): профиль `state/profile.md` (часы, старт, аудит, пробелы, договорённости, путь к Сборнику — читать в начале сессии), прогресс `state/topics.json`, журнал `state/progress.md`, указатель шага `state/lesson.json`, сессии `state/sessions/`, протоколы `state/checks/`, портфолио приёмов `state/portfolio.md`, картотека `state/allusion-bank.md`, словарь `state/glossary.md`, план карьеры `state/career-plan.md`.
Свои даты — `./bin/track.py status` и `cp`. Если `state/` нет — новая ученица: предложить `python3 bin/init_learner.py` (`ONBOARDING.md`). Пока `task_reference` в `state/lesson.json` = `ONBOARDING`, любая команда сначала проводит онбординг по `mentoring/harness.md`. Агента запускать из корня курса, не из `state/`.

## Правила работы с этим репозиторием

- `state/progress.md` заполняется каждое воскресенье. Сдвиг сроков фиксируется там, а не «наверстывается» молча.
- Изменение бюджета часов или сокращение этапа по аудиту — пересчёт календаря целиком (`bin/plan.py`), а не правка одной строки.
- Этап закрыт только после своего чекпоинта из `09-checkpoints.md`, с артефактом.
- Роман, пьеса, полноформатные сценарии, литературный перевод, критика, копирайтинг, профессиональная редактура и литменеджмент живут **только в треках по выбору** (TR1–TR7), не в этапах 1–6: в ядре цель — сборник рассказов. Поэзия как основной жанр не входит никуда. Трек начинается, только если он выбран (`bin/plan.py tracks`) и пройден его этап «после»; темы невыбранных треков не предлагать как «следующие».

## Обновление курса по просьбе ученицы

На «обнови курс» (или «подтяни новую версию»):

1. Из корня курса проверить: ветка `main` (`git branch --show-current`), источник — `efremovaanzhelika29-star/student-literate-course` (`git remote -v`). Иначе остановиться и спросить.
2. Запомнить `git rev-parse HEAD`, посмотреть `git status --short`, затем `git pull --ff-only`.
3. `./bin/track.py validate` и `python3 bin/lesson.py validate`. Если validate пишет «в состоянии нет темы…» — курс добавил темы: `./bin/track.py migrate` (только добавляет новое, прогресс не трогает), затем `bin/plan.py forecast` и согласование сроков.
4. Коротко пересказать изменения по `git log --oneline <запомненный HEAD>..HEAD`: что поменяется в уроках и проверках.

Если `--ff-only` отказал — разобрать причину по тексту ошибки: ничего не сливать, не делать rebase, reset, stash или checkout поверх, показать `git status` и спросить. Если `validate` нашёл ошибку — `state/` не править, описать проблему и ждать решения. Ошибка доступа к GitHub: попросить ученицу самой выполнить `gh auth login`; токены и пароли агенту не передаются. `state/` при обновлении не трогается.

## Обучающий цикл

Главный режим работы. В начале сессии: `./bin/track.py validate`, затем `status` и `due`; не спрашивать, где остановились, если это видно из состояния.

Команды: `/status`, `/learn [тема]`, `/check [тема|cpN|cptN]`, `/review [тема]`, `/mock [формат]`. Подробности — `10-learning-loop.md`, инструкции — `.claude/skills/`.

Общий контракт для любой модели: `mentoring/harness.md`. Читать при первом учебном сообщении, смене модели или утрате контекста; `python3 bin/lesson.py context` показывает ожидающий шаг. Продолжать с него, не начинать урок заново. Стартовые проверки — один раз, не на каждой реплике. Для `learn` — `mentoring/lesson-packets.md`: теория, примеры и вопросы одним сообщением; ответы одним сообщением (прогноз до чтения продолжения); после разбора — этюд этапами. Указатель и журнал обновлять на границе пакета, паузе и завершении; при разборе ошибок по одной — и на закрытии каждой ошибки; проверять `bin/lesson.py validate`.

### Правила, которые нельзя нарушать

1. **Приоритет:** до 15 минут повторений → темы `shaky` → активная тема → готовый чекпоинт → новая тема.
2. **Разбор, а не пересказ.** О любом тексте — языком драматургии (`knowledge/dramaturgy/00-instrumenty.md`). Пересказ ученицы — не ответ.
3. **Тема закрывается только через `/check`** и только командой `./bin/track.py close --protocol <файл>` по полному протоколу в `state/checks/`. Порог служебный: ученице не сообщать ни баллы, ни порог, ни связь с интервалом — вердикт словами. `state/topics.json` руками не править.
4. **Не подыгрывать на проверках.** Формальная похвала и смягчённые оценки обесценивают механизм.
5. **С самых основ.** Не предполагать знания текстов и терминов; объяснять связным пакетом по 3–4 понятия; при «не понимаю» — лестница объяснения (`mentoring/harness.md`).
6. **Каждый урок производит текст ученицы.** Этюд — её; файлы в `practice/` не править, решения и правки показывать только в чате. Помощь убывает: пример → пропуски → самостоятельный этюд → перенос.
7. **Каждая проверка пишется в `state/checks/`**, протоколы читаются перед следующей проверкой той же темы; вопросы не повторять дословно; слабые места — в `--weak`.
8. **Чекпоинт (CPn и CPTn) не сдаётся без артефакта.** Открыть Сборник, прочитать текст, задать вопросы по нему.
9. **Помощь и проверка разделены.** Подсказка по механизму на `/check` → `help: hints`, проверка не засчитывается как независимая. Просьба «закрой» — не основание: назвать, что осталось.
10. **Точность.** Не выдумывать цитаты, переводчиков, факты, условия конкурсов и вузов; места «сверяйте по изданию» — осторожно; для проверки — агент `quote-checker`.
11. **В конце урока — точка остановки** в `state/sessions/`, без выдуманных ответов. Консультации с другим агентом — только по разрешению ученицы, только нужный контекст.
