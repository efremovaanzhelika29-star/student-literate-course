# Лекционный курс: теоретическая база для конспектирования

Это **справочник по контексту**: эпохи, авторы, мифы, термины. **Ядро курса — мастерская разборов в `dramaturgy/`**: там произведения разбираются как механизмы, а не пересказываются. Пересказы в лекциях — только ориентир, чтобы понимать, откуда текст. Он написан для обучения с нуля: предварительных знаний не нужно. Каждая лекция самодостаточна, но порядок важен — поздние лекции опираются на понятия ранних.

## Как устроена каждая лекция

1. **Зачем это знать** — что даёт тема писателю и актёру.
2. **Ключевые термины** — выписывайте в словарь (отдельная тетрадь или файл `student/glossary.md`).
3. **Конспект** — основной текст. Жирным выделено то, что обязательно должно попасть в ваш конспект.
4. **Таблицы** — переносите целиком: по ним удобно повторять.
5. **Расширение кругозора** — то, чего нет в школьных программах, но что знает образованный читатель.
6. **Для актёра** — как тема работает на сцене и в кадре (не во всех лекциях).
7. **Вопросы для самопроверки** — ответьте письменно, не заглядывая в текст.
8. **Практикум** — три уровня:
   - **Базовый** — закрепление знаний;
   - **Продвинутый** — анализ и сравнение;
   - **Творческий** — применение в собственной прозе (и/или на сцене).

## Как конспектировать (метод Корнелла, адаптированный)

Разделите страницу на три зоны:

```
┌───────────────┬─────────────────────────────────────┐
│  ВОПРОСЫ      │  КОНСПЕКТ                           │
│  и ключевые   │  тезисы своими словами,             │
│  слова        │  даты, имена, цитаты                │
│  (заполнить   │                                     │
│  после        │                                     │
│  лекции)      │                                     │
├───────────────┴─────────────────────────────────────┤
│  РЕЗЮМЕ: 3–5 предложений — суть лекции              │
└─────────────────────────────────────────────────────┘
```

Правила:
- **Своими словами.** Переписывание дословно не учит. Исключение — цитаты и определения терминов.
- **Цитата = цитата + источник + контекст.** Без источника цитата в конспекте бесполезна.
- **Связи на полях.** Видите параллель с другой лекцией — пишите стрелку «→ Л7, Иов».
- **Через сутки** закройте правую колонку и ответьте на вопросы левой. Ошибки → в картотеку `student/allusion-bank.md`.

## Связь с программой

Каждой неделе `curriculum/program.md` соответствует лекция (см. колонку «Лекция» в программе). Наставник начинает тему с проверки, прочитана ли и законспектирована ли лекция, а потом спрашивает по ней.
