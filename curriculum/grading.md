# Система оценивания

Построена по модели НИУ ВШЭ: 10-балльная шкала, накопленная оценка, итоговый контроль, блокирующие элементы.

## Шкала

| Балл | Оценка | Что это значит в нашем курсе |
|---|---|---|
| 10 | отлично | Ответ уровня публикуемого эссе: точные цитаты, неочевидные связи между традициями, собственная мысль |
| 9 | отлично | Безошибочно, глубоко, с межкультурными параллелями |
| 8 | отлично | Точно и полно, параллели есть, но ожидаемые |
| 7 | хорошо | Верно, но с мелкими неточностями (дата, строка, имя персонажа) |
| 6 | хорошо | В целом верно, анализ поверхностный |
| 5 | удовлетворительно | Знание сюжета без понимания функции; цитаты приблизительные |
| 4 | удовлетворительно | Минимально приемлемо: основное знает, связи не видит |
| 3–1 | неудовлетворительно | Фактические ошибки, подмена текста пересказом/экранизацией |
| 0 | — | Не сдано или ответ выдуман (блеф при незнании текста) |

## Формула модуля

```
О_накоп = 0,25·О_опросы + 0,35·О_семинары + 0,40·О_письм
О_итог  = 0,6·О_накоп + 0,4·О_экзамен
```

- **О_опросы** — среднее за разминки по картотеке и короткие тесты (`/quiz`).
- **О_семинары** — среднее за семинарские обсуждения (`/seminar`).
- **О_письм** — среднее за письменные работы: аналитические эссе и творческие задания (`/lesson`, `/workshop`).
- **О_экзамен** — модульный экзамен (`/exam`).

Округление арифметическое и только для `О_итог`. Если `О_накоп ≥ 8`, студент может получить «автомат» — `О_итог = О_накоп` — при условии, что все блокирующие элементы сданы.

## Блокирующие элементы

Модуль **не засчитывается**, пока не выполнено:

1. **Теоретический минимум**: конспекты всех лекций модуля + коллоквиум (по 3 вопроса для самопроверки на лекцию, ≥ 70% верных ответов).
2. **Читательский минимум**: все произведения уровня A данного модуля прочитаны. Для каждого — подтверждение: 3 вопроса по тексту, на которые нельзя ответить по пересказу из лекции (деталь, сцена, цитата и её контекст).
3. **Цитатный минимум**: 80% записей картотеки модуля воспроизводятся точно (автор, произведение, контекст).
4. **Практикум**: выполнено не менее одного задания базового и одного творческого уровня из каждой лекции модуля.
5. **Творческая работа модуля**: рассказ или его фрагмент с отсылками (для актёрского трека допустима замена: монодрама/инсценировка + исполнение на видео), оценка ≥ 4.

## Дедлайны и штрафы

- Сдача позже срока: −1 балл за каждые сутки опоздания, максимум −3; после трёх суток — 0.
- Перенос без штрафа возможен, если попросить **до** дедлайна (не чаще одного раза в модуль).
- Пересдача экзамена — одна, максимум за пересдачу — 8.

## Рубрики

### Аналитическое эссе (до 10)

| Критерий | Баллы |
|---|---|
| Тезис: ясный, спорный, доказуемый | 0–2 |
| Работа с текстом: точные цитаты с указанием места, их анализ, а не иллюстрация | 0–3 |
| Контекст: миф/архетип, история, параллели с другими канонами | 0–2 |
| Композиция и логика аргумента | 0–2 |
| Язык и стиль | 0–1 |

### Творческое задание с отсылками (до 10)

| Критерий | Баллы |
|---|---|
| Точность источника: отсылка верна, не искажена непреднамеренно | 0–2 |
| Функциональность: отсылка работает на смысл (углубляет, иронизирует, предвещает), а не украшает | 0–3 |
| Дозировка и встроенность: считывается подготовленным читателем, не мешает неподготовленному | 0–2 |
| Оригинальность переосмысления | 0–2 |
| Качество прозы | 0–1 |

### Устный ответ / семинар (до 10)

| Критерий | Баллы |
|---|---|
| Знание текста (детали, цитаты, кто/где/когда) | 0–4 |
| Интерпретация и аргументация | 0–3 |
| Межкультурные связи | 0–2 |
| Точность терминологии | 0–1 |

### Опрос по картотеке (до 10)

Доля точных ответов × 10. Ответ засчитывается, если названы цитата/образ, источник **и** контекст (кто говорит или что происходит). Без контекста — половина балла.

### Конспект лекции (зачёт / незачёт + балл в «Письменные» по желанию)

| Критерий | Баллы |
|---|---|
| Все обязательные (выделенные жирным) понятия и таблицы лекции отражены | 0–4 |
| Своими словами, а не переписано; есть резюме (3–5 предложений) | 0–2 |
| Колонка вопросов/ключевых слов заполнена | 0–2 |
| Есть связи с другими лекциями (стрелки на полях) | 0–2 |

Зачёт — от 6 баллов.

### Актёрское задание (до 10): чтение, монолог, этюд

| Критерий | Баллы |
|---|---|
| Понимание текста: событие, обстоятельства, контекст произведения | 0–3 |
| Действие: ясно, чего добивается персонаж/чтец и от кого | 0–3 |
| Логика речи: ударения, паузы, перспектива, сохранение стиха | 0–2 |
| Видения и подтекст: за словами есть жизнь | 0–2 |

Оценивается по видеозаписи или описанию исполнения. Наставник оценивает **литературно-аналитическую** сторону и логику речи; пластика, голос и сценическое самочувствие — компетенция живого педагога, и Наставник прямо об этом говорит.
